# Trained Models Directory

This directory is reserved for saved models generated during **Stage 2 (Model Development & Training)**.

## Expected Files
- `animal_cnn_best.keras` or `animal_classifier.keras`: Saved model architecture, weights, and optimizer state.
- `class_indices.json`: JSON mapping between class labels and numerical indices.

> [!NOTE]
> No model files are generated during Stage 1. Models will be created and saved here during Stage 2.
